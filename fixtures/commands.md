## Viewer commands

| Command     | Effect                           |
| ----------- | -------------------------------- |
| `!song`     | Current track in chat            |
| `!so @user` | Shoutout for the tagged streamer |
| `!uptime`   | How long we've been live         |
| `!lurk`     | Lets the chat know you're around |

## Mod commands

- `!slow <seconds>` — set slow mode
- `!shoutout <user>` — force a shoutout
- `!clear` — wipe the chat

> Commands are case-insensitive but the underscore is not optional.
