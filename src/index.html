DocPanel

A panel on your channel with multiple pages: about, rules, FAQ, schedule — viewers flip through them with ‹ › arrows.

How it works

Your pages are plain .md (Markdown) text files plus a single list file index.json. You put them online (for example, on GitHub), and the extension loads them directly and shows them on the panel.

The key part: to change text on the panel, just edit the .md file. Nothing to reinstall, no re-approval from Twitch needed.

Set up in 5 minutes

  1. Create your pages. Each document is a .md file. Start the file with a title: 
    ---
title: About my channel
---

Hi! I stream on Tuesdays...
  2. Make a list. Create an index.json file — it tells the panel which pages to show and in what order: 
    [
  { "id": "about", "title": "About", "url": "about.md" },
  { "id": "rules", "title": "Rules", "url": "rules.md" },
  { "id": "faq", "title": "FAQ", "url": "faq.md" }
]

    id — any unique word, title — the name shown on the arrows, url — file name next to index.json.

    Don't want to write index.json by hand? There's an experimental tool that generates it from your .md files automatically (reading titles and page order from the file headers) — builder/build.ts in the extension repo. Manual editing works just fine too.

  3. Put it all online. The easiest way is a public GitHub repository: upload your .md files and index.json there. Once uploaded, the files become available through a link like this: 
    https://cdn.jsdelivr.net/gh/YOUR_NAME/your-repo@main/index.json

    Replace with your GitHub username and repository name. Test the link: open it in a browser — you should see the index.json text.

  4. Connect it to the panel. On your channel: Extension Manager → Configure for DocPanel → paste the link to index.json → "Load list" → arrange the order, hide what you don't need → "Save". Done — the panel is live.

Updating

Edit a .md file → save → changes appear on the panel automatically, within a few hours (due to caching, see below). Page order and hiding are changed in the control panel (Configure) without touching the files.

Why changes aren't instant: caching

Files are served through the jsDelivr CDN, which caches them — that's why the panel loads fast, but not instantly after you edit. What you put after @ in the link controls the speed:

What's in the link Updates When to use
@main within a few hours Normal mode — edit text, it arrives on its own
@v2 (a version tag) never, frozen forever Lock a page as-is
Saved your edits but the panel is still old? Wait a couple of hours, or purge the cache manually at jsdelivr.com/tools/purge — paste your link there and hit Purge.
Tip: to make rare important edits (say, rewritten rules) appear instantly: publish them and change @main to @v2, @v3… in the link in the control panel — the panel switches immediately.

What Markdown supports

Headings (##), paragraphs, bold, italic, ~~strikethrough~~, code, lists (including checkboxes - [ ]), links, images, quotes (>), divider ---.

HTML, tables, and code blocks are skipped by the panel — just don't use them. Reference images in text with relative paths (![](pics/me.png)) and keep them next to the .md file. Images must be https.
